# 오늘의 AI 브리핑 🤖

국내 AI 관련 뉴스를 한눈에 확인할 수 있는 뉴스 브리핑 웹사이트입니다.

생성형 AI, AI 반도체, AI 정책에 관한 뉴스를 카테고리별로 살펴보고, 각 기사의 핵심 내용을 빠르게 파악할 수 있습니다.

## 🔗 사이트 바로가기

[오늘의 AI 브리핑 보기](https://rnskdud700.github.io/-Mini-Project/)

## ✨ 주요 기능

- 국내 AI 뉴스 목록 제공
- 최신순 뉴스 정렬
- 카테고리별 필터링
  - 전체
  - 생성형 AI
  - AI 반도체
  - AI 정책
- 기사 미리보기 제공
- 핵심 이슈와 중요성 요약
- 기사 원문 링크 제공
- 새로고침 및 마지막 확인 시간 표시
- 반응형 웹 디자인

> 새로고침 버튼은 저장된 뉴스 데이터를 다시 불러오는 기능이며, 새로운 뉴스를 자동으로 수집하는 기능은 제공하지 않습니다.

## 🛠 사용 기술

- HTML
- CSS
- JavaScript
- JSON
- GitHub Pages

## 📁 주요 파일

```text
-Mini-Project/
├── index.html
├── style.css
├── script.js
└── news.json
```

- `index.html`: 페이지 구조
- `style.css`: 화면 디자인과 반응형 스타일
- `script.js`: 뉴스 표시, 필터 및 새로고침 기능
- `news.json`: 화면에 표시할 뉴스 데이터


## 🎯 제작 목적

빠르게 변화하는 AI 관련 소식을 사용자가 짧은 시간 안에 이해할 수 있도록 핵심 정보 중심의 뉴스 브리핑 페이지를 제작했습니다.
